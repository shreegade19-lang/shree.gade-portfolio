# Shree Gade — Personal Portfolio

A modern, responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. Designed to deploy directly on GitHub Pages.

## Run locally

No build tools are required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local server, you can use the VS Code Live Server extension (optional).

## Customize before publishing

Open `index.html` and replace these placeholder details in the Contact section:

- `your-email@example.com` with your email address
- `https://github.com/yourusername` with your GitHub profile
- `https://www.linkedin.com/in/yourusername` with your LinkedIn profile

You can edit section text, interests, learning journey, skills, and project cards directly in `index.html`. Adjust colors, spacing, and design in `styles.css`.

## Publish with GitHub Pages

1. Create a GitHub account or sign in.
2. Create a new repository named **`yourusername.github.io`** (replace `yourusername` with your GitHub username) for a user site.
3. Upload the files in this folder to the root of that repository: `index.html`, `styles.css`, `script.js`, `favicon.svg`, and `README.md`.
4. In your repository, open **Settings → Pages**.
5. Under **Build and deployment**, set Source to **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait for GitHub Pages to finish publishing. Your site will be available at `https://yourusername.github.io/`.

If you use a repository with a different name (for example `portfolio`), your URL will usually be `https://yourusername.github.io/portfolio/`.
